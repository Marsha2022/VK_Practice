# Как запустить проект
Клонировать проект
```
git clone https://github.com/Marsha2022/VK_Practice
cd data-crawler
```
Установить щависимости
```
pip install -r requirements.txt
```
Запуск
```
python3 main.py
```
В интерактивном меню выберите нужный пункт:
```
============================================================
ГЛАВНОЕ МЕНЮ
============================================================
  1. Скачать изображения (Bing, асинхронно)
  2. Скачать видео (YouTube, асинхронно)
  3. Сгенерировать CSV таблицы
  4. Запустить ВСЁ (асинхронно)
  5. Тестовый запуск (10 картинок, 2 видео)
  0. Выход
------------------------------------------------------------

Ваш выбор (0-5): 
```

# Алгоритм работы
## Изображения (DuckDuckGo)
1. Загружаются существующие хеши MD5 из папки images/ (дедупликация).  
2. Для каждого запроса (например, "cat") асинхронно: 
* Циклически выбирается регион из списка (80+ стран). 
* Выполняется синхронный поиск DDGS().images() в отдельном потоке (run_in_executor). 
* Из полученных URL изображений создаются задачи на скачивание (до 10 параллельно, семафор). 
* Каждое изображение проверяется на дубликат по MD5 перед сохранением. 
* Добавляются случайные задержки между регионами и скачиваниями.  
3. Процесс продолжается, пока не набрано MAX_IMAGES_PER_QUERY уникальных изображений. 

## Видео (YouTube)
1. Для каждого запроса асинхронно выполняется поиск через yt-dlp --flat-playlist --dump-json. 
2. Из результатов извлекаются URL и заголовки видео. 
3. Одновременно запускается до 3 процессов yt-dlp (семафор) для скачивания видео. 
4. Каждое видео сохраняется в папку videos/<query>/ с именем {title}_{id}.mp4. 
5. При превышении лимита размера всех видео загрузка останавливается. 

## CSV (генерация)
1. Если USE_OPENAI=True, через ProxyAPI/OpenAI генерируется CSV_SEED_ROWS уникальных строк (книга, жанр, автор, тираж, популярность). 
2. В противном случае используются встроенные шаблоны. 
3.Seed‑датафрейм расширяется до CSV_TOTAL_ROWS путём случайных повторений и вариаций (тираж ±20%, популярность ±1). 
4. Результат разбивается на несколько CSV-файлов (по умолчанию 10) в папке csv_datasets/.
